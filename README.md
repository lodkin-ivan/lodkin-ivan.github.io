# Siemens C65 Camera

Веб-приложение (PWA) для iPhone, имитирующее камеру старого телефона Siemens C65: VGA 640×480, RGB565, холодный оттенок, шум, виньетка, сильное JPEG-сжатие. Интерфейс — видоискатель в рамке телефона в стиле меню C65.

Демо: https://lodkin-ivan.github.io/

## Использование на iPhone
1. Откройте ссылку в Safari и нажмите «Камера», разрешите доступ.
2. «Поделиться → На экран Домой» — приложение запускается как нативное и работает офлайн.

Камера в iOS работает только по HTTPS (или на `localhost`).

## Управление
- **Кнопка спуска** — снять кадр (звук затвора, вспышка экрана).
- **▲ / ▼** — цифровой зум (до 4×); также щипок двумя пальцами.
- **Опции** — разрешение (VGA/QVGA), дата на фото, основная/фронтальная камера.
- **Галерея** — нажмите на миниатюру, чтобы выбрать, повторно — открыть. «Опции» → Открыть / Сохранить / Удалить.
- **Сохранить** открывает меню iOS «Сохранить изображение»; запасной вариант — скачивание файла.

Снимки хранятся в `localStorage` браузера (при нехватке места старые удаляются).

## Структура
| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | разметка и оформление (рамка, экран, меню) |
| `app.js` | камера, цикл превью, эффект, съёмка, галерея, меню |
| `presets.js` | параметры эффекта; `c65` — первый пресет, сюда добавляются другие телефоны |
| `sw.js`, `manifest.webmanifest` | PWA: офлайн-кэш, установка на главный экран |
| `fonts/` | пиксельные шрифты Pixelify Sans и VT323 (SIL OFL) |

## Локальный запуск
```sh
python3 -m http.server
```
Откройте `http://localhost:8000` в Chrome с веб-камерой.

## Деплой
Статический сайт, сборка не нужна. GitHub Pages: Settings → Pages → Deploy from branch `main`, `/ (root)`. После изменений поднимайте версию кэша `CACHE` в `sw.js`.
